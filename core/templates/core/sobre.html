Sobre o Projeto

A primeira Feijoada Week aconteceu de 4 a 11 de dezembro de 2019, entre um grupo de amigos que trabalhavam juntos em uma fintech de São Paulo. A ideia do idealizador era simples: comer feijoada durante sete dias seguidos. Não foi possível cumprir a meta integralmente — no sábado houve uma falha — mas, nos dias úteis, o desafio foi levado a sério. Combinando com o chefe uma pausa estendida de duas horas para o almoço (compensada em outros horários), foi possível reunir colegas e visitar diferentes restaurantes da cidade que serviam feijoada todos os dias da semana. Um deles precisou ser repetido por questões logísticas, mas a missão foi cumprida com entusiasmo e o evento, um sucesso. Foi ali que nasceu o espírito da Feijoada Week.

O blog FeijoadaWeek.com.br nasceu como um projeto pessoal com dois objetivos principais: manter a prática contínua no uso do framework Django e explorar tecnologias modernas de infraestrutura, como os serviços da AWS. Ao mesmo tempo, celebra de forma leve e divertida uma paixão nacional — a feijoada!

Além de ser uma vitrine gastronômica com avaliações, fotos e dicas sobre os melhores lugares para comer feijoada no Brasil (começando por São Paulo), o projeto é também um laboratório técnico em constante evolução. Aqui testamos funcionalidades, padrões e integrações modernas, unindo tecnologia e cultura.

Acompanhe o código-fonte e as atualizações pelo repositório no GitHub:
👉 github.com/ahrocha/feijoadaweek-python-django

Arquitetura e Tecnologias

A aplicação é desenvolvida em Python com o framework Django, utilizando MariaDB como banco de dados e Tailwind CSS no frontend. As imagens do site ficam hospedadas na AWS S3.

Infraestrutura:

  • EC2: migrei recentemente para uma instância EC2 compartilhada com outras aplicações, com deployment feito via Github Actions.
  • AWS RDS (MariaDB): banco relacional gerenciado com backups automáticos.
  • AWS S3: armazenamento público para imagens e assets estáticos.
  • RIP AWS App Runner: backend em Django, com CI integrado ao GitHub.
